# Weekly Maker

Vtuberや活動者さん向けの週間スケジュールの画像を作成するWebアプリです。

[アプリページはこちら](https://kazuki-huyume.github.io/weekly-maker/)

## 特徴

- **簡単操作**: 曜日ごとの予定を入力するだけで、見やすいスケジュール表を作成できます。
- **カスタマイズ可能**: フォントやテーマカラー、背景画像、キャラクター画像などを自由に変更可能。
- **カスタムフォント対応**: ローカルにあるお好みのフォントファイル（`.ttf`, `.otf`, `.woff`, `.woff2`）をアップロードして、アプリ内で即座に使用可能。
- **多彩なテンプレート**: シンプル＆ポップ、サイバーパンク風、フローティング・カレンダー、ウェーブ＆グラデーションなど、個性豊かなテンプレートを多数搭載。
- **画像保存**: 作成したスケジュール表をPNG形式で保存できます。

## 使い方

1. **開始日を設定**  
   「開始日」欄でスケジュールの開始日を選択します。

2. **テンプレートを選択**  
   「テンプレート」ドロップダウンから、好みのデザインスタイルを選択します。

3. **カスタムフォントを追加（任意）**  
   「カスタムフォント」欄からお手持ちのフォントファイル（`.ttf` / `.otf` / `.woff` など）をアップロードすると、タイトルおよび本文のフォント選択肢に自動で追加され、即時適用されます。

4. **フォントを選択**  
   「タイトルフォント」および「本文フォント」のドロップダウンから、使用するフォントを選びます。

5. **テーマカラーを選択**  
   カラーボタンまたはカラーピッカーを使用して、スケジュール表のメインテーマカラーを設定します。

6. **キャラクター画像を追加（任意）**  
   「キャラクター画像」欄で画像をアップロードし、ドラッグで位置を調整したり、ホイールで拡大縮小できます。  
   「位置・サイズリセット」ボタンで初期状態に戻すことも可能です。

7. **背景設定を変更（任意）**  
   「エリア背景設定」で、単色カラーまたは背景画像を選択できます。背景画像をアップロードしたり、削除することも可能です。

8. **ひとこと/クレジットを追加（任意）**  
   イラスト領域の右上に表示するひとことやクレジットを入力できます。

9. **曜日ごとの予定を入力**  
   各曜日の予定と時間を入力します。「おやすみ」ボタンを押すと、その日の予定を「おやすみ」に設定できます。

10. **スケジュール表を保存**  
    「名前を付けて画像を保存する」ボタンをクリックして、作成したスケジュール表をPNG形式で保存します。

## テンプレートの追加方法

1. `templates`フォルダ内に新しいテンプレートフォルダを作成します。
2. `config.json` や描画ロジックを記述した `render.js` などのファイルを配置します。
3. ルートディレクトリの `manifest.json` に新しいテンプレートの情報を追記します。

## 必要な環境

- 最新のWebブラウザ（Google Chrome、Firefox、Edgeなど）

## 注意事項

- キャラクター画像や背景画像、フォントファイルをアップロードする際は、著作権や利用規約に注意してください。
- 保存機能はブラウザの仕様に依存します。一部のブラウザでは動作しない場合があります。
